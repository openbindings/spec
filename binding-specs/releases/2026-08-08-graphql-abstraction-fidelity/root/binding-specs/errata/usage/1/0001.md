# `openbindings.usage@1` erratum 1: publication immutability wording

Published: 2026-07-24
Status: editorial clarification

## Passage

The opening publication paragraph says that a “compatible clarification may
revise this document in place.”

## Clarification

Read that clause as: “compatible clarification follows the openbindings
project’s published-specification errata process.” Once published, the defining
document for `openbindings.usage@1` is immutable. A non-behavioral clarification
is appended as errata; a change to accepted sources or required, permitted, or
refused observable behavior publishes a new binding-specification revision.

## Why this changes no behavior

This corrects publication-process wording only. It changes no accepted KDL
artifact, command or argument mapping, process invocation, configuration point,
refusal, value lane, exit-status classification, or observable behavior.

## Affected rules

Publication metadata adjoining core OBI-B-01 and OBI-B-03; no Usage binding rule
is changed.
