# `openbindings.grpc@1` erratum 1: publication immutability wording

Published: 2026-07-24
Status: editorial clarification

## Passage

The opening publication paragraph says that a “compatible clarification may
revise this document in place” and then discusses evaluating such a
clarification in every citing specification’s context.

## Clarification

Read the first clause as: “compatible clarification follows the openbindings
project’s published-specification errata process.” Read the following
cross-specification requirement as applying to any proposed clarification: it
must be non-behavioral in both the gRPC specification and every exact-identifier
citer to qualify as errata. Otherwise it publishes a new
binding-specification revision. The defining `openbindings.grpc@1` document is
never revised in place.

## Why this changes no behavior

This reconciles publication wording with the already-enforced immutable
publication record. It changes no accepted descriptor, RPC mapping, message
correspondence, cardinality, configuration point, refusal, status mapping, or
invocation behavior in gRPC or Connect.

## Affected rules

Publication metadata adjoining core OBI-B-01 and OBI-B-03; no gRPC binding rule
is changed.
