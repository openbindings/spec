# `openbindings.asyncapi@1` erratum 1: publication immutability wording

Published: 2026-07-24
Status: editorial clarification

## Passage

The opening publication paragraph says that a “compatible clarification may
revise this document in place.”

## Clarification

Read that clause as: “compatible clarification follows the openbindings
project’s published-specification errata process.” Once published, the defining
document for `openbindings.asyncapi@1` is immutable. A non-behavioral
clarification is appended as errata; a change to accepted sources or required,
permitted, or refused observable behavior publishes a new binding-specification
revision.

## Why this changes no behavior

This corrects publication-process wording only. It changes no accepted AsyncAPI
artifact, channel or operation mapping, message correspondence, transport or
configuration choice, refusal, outcome classification, or invocation behavior.

## Affected rules

Publication metadata adjoining core OBI-B-01 and OBI-B-03; no AsyncAPI binding
rule is changed.
