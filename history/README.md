# Design history

This directory preserves non-normative records that explain how the current
working specification was reached. These files are useful for design archaeology
and review, but they are not specifications, conformance requirements, current
issue lists, or release notes.

Current normative and implementation-facing material is indexed from the
repository [`README.md`](../README.md). Current work belongs in issues and pull
requests; user-visible changes belong in [`CHANGELOG.md`](../CHANGELOG.md).

- [`0.2-core-analysis.md`](0.2-core-analysis.md) — the adversarial content
  analysis that preceded the 0.2 core rewrite.
- [`0.2-core-analysis-decisions.md`](0.2-core-analysis-decisions.md) — the
  associated discussion and decision ledger.
- [`0.2-development-log.md`](0.2-development-log.md) — the detailed
  chronological record of changes made while developing the 0.2 draft.
